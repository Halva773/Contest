# Разбиение DataFrame по датам

Функция `chunk_by_datetime` разбивает pandas DataFrame на чанки заданного
желаемого размера. Все строки с одинаковым временем остаются в одном чанке.
Каждый чанк достигает желаемого размера, кроме последнего: он может быть
меньше. Если одинаковых дат много, чанк может быть больше желаемого размера.

```python
import pandas as pd

from chunker import chunk_by_datetime

dates = pd.date_range("2023-01-01", periods=6, freq="s")
frame = pd.DataFrame({"dt": dates.repeat(3)})

for chunk in chunk_by_datetime(frame, "dt", chunk_size=5):
    print(len(chunk))  # 6, 6, 6
```

Функция принимает столбец типа datetime, в том числе с часовым поясом.
Остальные столбцы и индекс сохраняются. Для перемешанных дат результат
упорядочен по времени; порядок строк с одинаковой датой сохраняется.
Пустой DataFrame не создаёт чанков. `NaT` вызывает ошибку: такую строку
нельзя однозначно отнести к дате.

Если даты уже отсортированы, функция находит конец чанка бинарным поиском и
отдаёт срезы исходного DataFrame без его полной копии. Для перемешанных дат
pandas группирует позиции строк и сортирует только уникальные даты. Это
требует O(n) дополнительной памяти и избегает сортировки всех столбцов.
Оба варианта возвращают генератор, поэтому список всех выходных DataFrame
в памяти не создаётся. Время работы: O(n) для отсортированного входа и
O(n + u log u) для перемешанного, где `u` — число разных дат.
